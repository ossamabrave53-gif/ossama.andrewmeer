Correction des scénarios 1 – Ossama Ettaliy

Scénario 2 : Création d'une plateforme collaborative pour des utilisateurs distants : Application pour une entreprise

1. Quel type d'application (Desktop, Web ou Mobile) choisiriez-vous pour ce projet, et pourquoi ?
application desktop .
car L’application doit fonctionner même lorsque la connexion Internet est instable ou absente, ce qui est plus fiable avec une application installée localement.
2. Quels langages et frameworks utiliseriez-vous pour développer cette application ?
C++ avec Qt
3. Quels sont les avantages du type d'application que vous avez choisi dans ce contexte (contrôle en temps réel, sécurité des données, stabilité sans connexion, etc.) ?
Sécurité locale, performance élevée, confidentialité des données.
4. Quels inconvénients ou limitations pourriez-vous rencontrer avec ce type d'application (performances, dépendance à l’internet, expérience utilisateur, etc.) ?
Déploiement complexe, compatibilité OS, mises à jour manuelles.
